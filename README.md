# Task Manager (C#)

A small console to-do list I wrote while learning C#. You can add tasks, list them, search them, mark them as done, delete them and see a few basic stats. Tasks are saved to a text file when you exit.

**Heads up:** this isn't a real tool and it isn't meant to be used for anything serious. It's just a practice project I wrote to get comfortable with the language: lists, exceptions, file reading/writing and method overloading.

## Running it

You'll need the .NET SDK installed. From the repo folder:

```bash
dotnet run --project GestorTareas
```
